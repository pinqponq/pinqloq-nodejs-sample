# Project standards

Shared standards come from **pinq-doq**, vendored under `.pinq-doq/` and copied into `.claude/rules/` (auto-loaded; do not import scoped rules). Skills are in `.claude/skills/`. Scripts and references are used in place from `.pinq-doq/`.

To refresh the shared standards, follow `.pinq-doq/tasks/update.md`.

This project uses Node.js, TypeScript and Express. Apply `common.md`; Kotlin and .NET conventions do not apply to the sample source.
